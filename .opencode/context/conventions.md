# Conventions

- [binding] TDD/DDD per `docs/00-method/`; anti-corruption at reseller boundaries. — See `docs/00-method/02-ddd.md` (verified 2026-11-06)
- [binding] DI via `src/container.ts`; repositories under `src/infrastructure/prisma/`; app services pure/domain logic in context dirs. — See `src/container.ts` (verified 2026-11-06)
- [binding] Path alias `@/*` → `./src/*` (tsconfig). Tests co-located `*.test.ts`. — See `tsconfig.json`, `package.json` (verified 2026-11-06)
- [binding] Route loading fallbacks: every non-API page needs a `loading.tsx` in its own dir or an ancestor up to `src/app`; loading files are server components with a default export, wrapped in `LoadingRegion` (role="status", aria-busy) with at least two `.skeleton` elements and no interactive elements. — See `src/app/loading-coverage.test.ts`, `src/app/loading.test.tsx`, `src/app/skeleton.tsx` (verified 2026-11-06)
- [binding] Back-office charts follow the spec's visualization grammar: partition bars only for disjoint parts of one total on one basis, bridges only for the signed recorded-to-live path, shared formatter and CSS colour tokens, an Arabic text alternative per graphic. — See `docs/03-specs/06-back-office.md` §Dashboard (`/management`) (verified 2026-11-06)
- [binding] Money is integer minor units plus an ISO currency code; construct via `src/shared/money.ts` (`money`, `majorToMinor`); floats are rejected at the boundary. — See `docs/01-domain/03-glossary.md`, `src/shared/money.ts` (verified 2026-11-07)
- [binding] `Setting.value` is LONGTEXT: settings keys hold large JSON blobs (e.g. the P2P history) that a bounded string column cannot hold; do not narrow the column. — See `prisma/schema.prisma`, `prisma/migrations/20261107000000_setting_value_longtext/migration.sql`, `src/treasury/application/p2p-rate-settings.ts` (verified 2026-11-07)
- [binding] P2P window/sync/outlier-sigma bounds are canonical in `src/shared/p2p-settings.ts` (re-exported by `src/treasury/application/p2p-rate-settings.ts`); the admin P2P route validates against them directly, so change a bound there, not in a subsystem copy. — See `src/shared/p2p-settings.ts`, `src/app/api/admin/settings/p2p/route.ts`, `src/treasury/application/p2p-rate-settings.ts` (verified 2026-11-07)
- [binding] Cross-context imports go through the bounded-context barrel (`src/<context>/index.ts`, e.g. `@/treasury`, `@/fulfilment`, `@/wallet`); deep `domain/`/`application/` paths are for intra-context use within that context. — See `src/treasury/index.ts`, `src/fulfilment/index.ts`, `src/wallet/index.ts`, `src/integration/binance-p2p/quote.ts` (verified 2026-11-07)
- [binding] Environment configuration is read only through `readEnv` in `src/env.ts` (the typed `Env`); routes pass `process.env` to it rather than reading individual keys at call sites. — See `src/env.ts`, `src/app/api/jobs/p2p/route.ts`, `src/api/container.ts` (verified 2026-11-07)
